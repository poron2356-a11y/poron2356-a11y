## 🚀 Featured Project: [SnapBolt](https://github.com/poron2356-a11y/SnapBolt) (Windows 10 / 11)

**SnapBolt** は、いつもの `Win + Shift + S` から「0.1秒起動・自動保存ゴミなし → 1クリック個人情報自動モザイク（`Ctrl + Shift + M`）＆境界自動検出ピクセル定規（`D`キー）→ 縦長スクロールキャプチャ → そのまま `Ctrl + V` 即貼り付け」に加え、**MP4/GIF 画面録画＆カット編集スタジオ**・**完全オフライン QRコード/OCR 読み取り** を1つに統合した Windows 10 / 11 ユーティリティです（[**窓の杜 3度掲載**](https://forest.watch.impress.co.jp/docs/digest/2155649.html) ／ [**Vector 公式収録**](https://www.vector.co.jp/soft/winnt/art/se529929.html) ／ [**Microsoft Store 公式認定アプリ**](https://apps.microsoft.com/detail/9MTBJHKWKM43)）。

*(English)* **SnapBolt** is a 0.1s native Windows 10/11 replacement for `Win + Shift + S` featuring **Zero Forced Auto-Save**, **1-Click Offline Auto-Redact PII (`Ctrl + Shift + M`)**, **Smart Edge-Detecting Pixel Ruler (`D` key)**, **Full-Page Scrolling Capture (`Ctrl + Shift + L`)**, built-in **MP4/GIF Recording Studio**, and **100% Offline QR/OCR** across 8 native languages.
