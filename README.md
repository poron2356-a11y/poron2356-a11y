## 🚀 Featured Project: [SnapBolt](https://github.com/poron2356-a11y/SnapBolt) (Windows 10 / 11)

**SnapBolt** は、「ウィンドウ自動枠合わせ → 3秒でモザイク・赤枠・矢印・SNS映え背景フレーム編集 → ファイル保存なしでそのまま `Ctrl + V` 即貼り付け」に加え、**MP4/GIF 画面録画＆カット編集スタジオ**・**完全オフライン QRコード/OCR 読み取り**・**1px 拡大鏡ルーペつき色スポイト（`#HEX` / `RGB`）** を1つに統合した Windows ユーティリティです（[**窓の杜 掲載ソフト**](https://forest.watch.impress.co.jp/docs/digest/2150874.html) ／ [**Microsoft Store 公式認定アプリ**](https://apps.microsoft.com/detail/9MTBJHKWKM43?hl=ja-jp&gl=JP)）。

*(English)* **SnapBolt** is an all-in-one native Windows 10/11 utility featuring Auto Window/UI Element Snap, 3-second Mosaic/Red-box/Step-number Annotation with 1-Click Beautifier Frame & zero-file `Ctrl+V` paste, an MP4/GIF Screen Recording & Trim Studio, 100% Offline QR/OCR Reader, and a 1px Magnifier Screen Color Picker (`#HEX`).
